# Images

Drop your photographs and screenshots here, then reference them from `src/data/story.js`
using a path that starts with `/images/…`, e.g.

```js
photo: '/images/school.jpg'
```

Recommended: JPG/WebP, 1600 px on the long side, under 300 KB each (compress with squoosh.app).
Anything left as `null` shows a clearly labelled placeholder inside the 3D world.
